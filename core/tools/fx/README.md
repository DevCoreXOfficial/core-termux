# fx

Tiny, open, native coding agent harness written in Zig.

**Package:** fx
**Author:** Vercel Labs
**Repository:** https://github.com/vercel-labs/fx
**Type:** AI coding agent (standalone Zig binary)
**License:** Apache-2.0

## Description

fx is a coding agent harness optimized for research and embeddability. It focuses on minimalism and performance with a ~6 MB binary, 10µs cold start, and minimal memory footprint.

## Dependencies

- None (standalone binary)

## Install

```bash
core install fx
```

## Uninstall

```bash
core uninstall fx
```

## Update

```bash
core update fx
```

## Notes

- Binary installed via official installer to `~/.local/bin/fx`
- Model-agnostic: works with local models, gateways, or provider APIs
- Extensible via skills, plugins, and MCP
