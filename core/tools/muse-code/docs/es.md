## Package Information

- **Nombre:** Muse Code
- **Autor:** Meta
- **Proyecto:** https://developer.meta.com/ai/products/muse-code/
- **Dependencias:** proot, curl, python

## What is it?

Muse Code de Meta es un agente de programación con IA para terminal que en Termux se ejecuta bajo `proot` y en Ubuntu/WSL mediante el instalador oficial.

## How to use it?

```bash
muse-code
muse
```
