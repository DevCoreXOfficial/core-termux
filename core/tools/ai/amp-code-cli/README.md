# AMP Code CLI

AMP is a coding agent by Sourcegraph that integrates with IDEs and the command line, providing unconstrained access to the best AI models.

**Package:** `@ampcode/cli`
**Author:** Sourcegraph
**Repository:** https://github.com/DevCoreXOfficial/core-termux
**Official:** https://ampcode.com
**Type:** glibc-binary

## Installation

```bash
core install ai --amp-code-cli
```

## Usage

```bash
amp                    # Interactive mode
amp "your prompt"      # Run with prompt
```
