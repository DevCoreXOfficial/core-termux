- **Tags:** ai, agent, coding

## ¿Qué es?

El agente que aprende tu estilo de programación.

## Binario y referencia CLI

**Binario:** `cmdc`

Salida real de `--help` y comandos comunes:

- **Binary:** `cmdc`

## ¿Cómo usarlo?

```bash
core install command-code        # instalar
core update command-code         # actualizar
core uninstall command-code      # eliminar
```
