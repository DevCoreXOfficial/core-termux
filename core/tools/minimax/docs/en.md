## What is it?

Generate text, images, video, speech, and music from the terminal

**Package:** mmx-cli  
**Author:** DevCoreX  
**Repository:** https://github.com/DevCoreXOfficial/core  
**Official:** https://github.com/MiniMax-AI/cli  
**Type:** AI CLI tool (npm global package)  
**License:** MIT

### Description

MiniMax CLI lets you generate text, images, video, speech, and music from any agent or terminal using MiniMax AI services.

### Dependencies

- Node.js LTS (nodejs-lts)
- npm
- git, ripgrep

### Install

```bash
core install minimax
```

### Uninstall

```bash
core uninstall minimax
```

### Update

```bash
core update minimax
```

### Notes

- Installed as a global npm package: `mmx-cli`
- Command: `mmx`
- Requires an API key from MiniMax

## How to use it?

```bash
core install minimax      # install
core update minimax       # update
core uninstall minimax    # remove
```
