## ¿Qué es?

A terminal-native AI coding partner—and an agent engine you can build on.

## Binario y referencia CLI

**Binario:** `qodercli`


## ¿Cómo usarlo?

```bash
core install qoder        # instalar
core update qoder         # actualizar
core uninstall qoder      # eliminar
```
