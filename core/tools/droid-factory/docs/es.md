## Información del Paquete

- **Nombre:** Droid Factory
- **Tags:** ai, agent, coding
- **Proyecto:** https://factory.ai
- **Dependencias:** ninguna requerida por Core

## ¿Qué es?

CLI del agente Droid de Factory para tu terminal.

## Binario y referencia CLI

**Binario:** `droid`

Salida real de `--help` y comandos comunes:

- **Binary:** `droid`

## ¿Cómo usarlo?

```bash
core install droid-factory        # instalar
core update droid-factory         # actualizar
core uninstall droid-factory      # eliminar
```



## Notas

- Plataformas soportadas: **termux, ubuntu, wsl**.
- En Termux algunas herramientas ofrecen varios métodos de instalación (menú interactivo); en Ubuntu/WSL se usan siempre métodos oficiales.
- Documentación completa en inglés: `core show droid-factory`.
