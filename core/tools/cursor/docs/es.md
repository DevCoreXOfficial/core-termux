## ¿Qué es?

Agente de programación con IA que corre en tu terminal.

## Binario y referencia CLI

**Binario:** `cursor`

Salida real de `--help` y comandos comunes:

- **Binary:** `cursor`

## ¿Cómo usarlo?

```bash
core install cursor        # instalar
core update cursor         # actualizar
core uninstall cursor      # eliminar
```



## Notas

- Plataformas soportadas: **termux, ubuntu, wsl**.
- En Termux algunas herramientas ofrecen varios métodos de instalación (menú interactivo); en Ubuntu/WSL se usan siempre métodos oficiales.
- Documentación completa en inglés: `core show cursor`.
