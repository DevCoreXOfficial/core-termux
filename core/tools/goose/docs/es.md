Agente de código abierto de Block con soporte de extensiones MCP.

## Binario y referencia CLI

**Binario:** `goose`

## ¿Cómo usarlo?

```bash
core install goose        # instalar
core update goose         # actualizar
core uninstall goose      # eliminar
```
