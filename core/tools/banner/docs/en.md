## What is it?

Customize Termux with Core Banner

**Package:** core-termux (banner config)  
**Author:** DevCoreX  
**Repository:** https://github.com/DevCoreXOfficial/core  
**Type:** Termux UI customization  
**License:** MIT

### Description

Configure a custom banner for Termux using Core. This package allows you to set a personalized welcome message that appears when you start Termux, enhancing your terminal experience.

### Dependencies

- Termux (base installation)

### Install

```bash
core install banner
```

### Uninstall

```bash
core uninstall banner
```

### Update

```bash
core update banner
```

### Notes

- Source file: `~/.local/share/core-termux/assets/banner/devcorex.txt`
- removes Termux welcome message: motd
- Restart Termux to apply changes

## How to use it?

```bash
core install banner      # install
core update banner       # update
core uninstall banner    # remove
```
